# CyIME 1.15.107

- **选词**。九键打两个字的词时，打到一半就给这个词：打「今天」打到 jin ti 不再出「近体」「吉姆哈」，打「知道」打到 zhi da 不再出「直达」，酒店、晚上、楼下、后悔这类常用词同样。九键只打一个词时，常用词不再被冷门同码词压到第二：时候不再先出事后，通知不再先出同志，样子、对象、消息、办法、印象等同样；你选过的词照旧按你的习惯排。14 键停手后读不通的拼音不再拼整句，换布局时清掉九键留下的上文，14 键停手整句不再接着九键上一句；偶尔一次补算超时不再停 5 分钟。
- **候选栏**。候选词设置的三张卡重画：默认、经典、右侧收起（原「收键盘」），写明各适合三键导航、全面屏手势还是随时收键盘；新手引导「按设备推荐配置」也问一次，按你的导航方式推荐。三套用法在空闲、打字、展开、联想时点左点右、左滑右滑都按各自的设计走。
- **九键**。长按数字键弹出「大写 数字 小写」一排，松手默认上屏数字。空格上滑出 0 的方向和别的数字键一样，跟着「底排标点固定上滑」和「反转上下滑方向」，动画也一样；开了以后空格右上角写着 0。数字键另一方向滑动可设全选、复制、粘贴等；滑行时同一条线的其他读音也进左栏（滑 94664 也有 xing）。
- **标点**。数字后的「。」「，」先上半角，接着打数字就留半角（3.14、1,000），打汉字、标点、空格、回车时改成全角。
- **键盘**。可选 123 和 !@# 对调、数字行和字母一样高、打开键盘时退出英文；上下滑输入符号的距离可调；符号键当 Ctrl 的时限最短 0.1 秒；几根手指交叠时按按下的先后出字。悬浮键盘开玻璃效果不再裂成上下两块，开动态背景时底下拖动条跟着一起动；拖到很小时整块按比例缩小，工具栏、字和按键一起缩，不再只把按键压扁。开了「回车发送」时长按回车换行（26 键、九键、笔画）。上下标页补齐下标字母。贴边拼音可以不显示纠正读音。
- **英文**。新增英文下一词（默认关）：打完一个词按空格给常跟在后面的词。Abc123、iPhone 这类字母加数字、中间大写的词，英文直出、九键、14 键、双拼打的也记住。
- **剪贴板和词库**。可选粘贴后把这条移到最前，卡片行数多一档、文字大小可调；WebDAV 等同步可选自动拉取间隔。我的短语可以从文件批量导入，导不进的行列出来；英文词导入去掉搜狗格式编码，导出带上英文词。候选里显示表情只给表情，不再出符号。
- **其他**。语音可选用蓝牙耳机的麦克风；韩语用 SenseVoice 识别。实体键盘可按应用直通，SYM 键开关符号页。折叠屏外屏、内屏分开记键盘高度和布局。滑动移光标到头不再发方向键收起键盘。开着模糊音点读音时模糊音的等价读音留在后面；导入的万象拼音可以点编码改拼音。
