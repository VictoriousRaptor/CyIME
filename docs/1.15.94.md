# CyIME 1.15.94

- **长句**。26 键打长句更准也更快：「我妈让我早点回家」「是不是又熬夜了」这类句子不再被同音词挤掉；每个字第一键的耗时降下来。整句末尾是单字时，候选里多给出同音的常用说法（见了你吗 / 见了你妈），首选不变。
- **双拼**。14 键双拼也能开模糊音和简拼；微软双拼有了九键、14 键和合并键布局版本；九键双拼不开模糊音也有拼音栏；可选自然码辅助码和小鹤形码（默认关）；26 键双拼可拖选整句局部改拼音。扩展里能装小鹤音形。
- **角标和数字行**。26 键角标按是否开数字行、显示上下哪一边分成六套，可跟随全角半角；开数字行后数字键不画角标，长按弹出 ½ 到 ⅛。长按输入角标默认 0.5 秒，三个以上选项的长按菜单按手指所在格选，不再一碰就弹。
- **外观**。液态玻璃强度分标准、加强、最强三档，默认标准和以前一样。幻灯片背景每张都能缩放和摆位置。键盘上的汉字按输入语言选字形。
- **笔画和注音**。笔画分词后保留短码单字、记住逐字选出的词，编码显示笔画；注音键盘用繁体字形，补收「妳」等台湾专用单字，删除键加宽。
- **方案**。刚打开的方案（如笔画）现在会马上编进键盘的切换面板。
- **翻译和 AI 插件**。翻译默认跟界面语言互译：中文界面打中文译成英文，打外文译成中文；在线可选讯飞机器翻译和讯飞星火 X2，AI 改写、AI 回复也可选星火 X2，插件设置只显示所选服务要填的项。插件在扩展市场更新。
- **开屏广告**。「关于 CyIME」里可以启用开屏广告，默认关。
- **其他**。九键可选把 0 键并入大回车；九键滑行出词后给出备选，点一下替换；空格上下滑移光标时每行振动一下；剪贴板设置放到设置首页；清空后撤回能恢复未完成的输入；剪贴板一次复制多张图片都能收下；底部留白横竖屏分开记；词库加了一批游戏名和网络新词，打 cyime 出 CyIME。

轻量版可以按需下载模型，完整版内置离线模型。两者使用相同版本号和安装序号，支持保留数据覆盖安装。
