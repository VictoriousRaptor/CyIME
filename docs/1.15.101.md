# CyIME 1.15.101

- **设置**。推荐配置页点进「更多配置」或别的页面再回来，停在原来的位置，选过的不丢；改按键符号的小框改到一半点了框外或返回，先问保存不保存；整排输入打空格就是空位，几个字的短语用「」括起来；语言与方案页按做事先后排，加「导入方案」一行；各页说明精简；存储空间的「清理」和标题对齐，0 B 的行不显示；插件设置的条目在卡片里直接改。
- **双拼和词库**。开着简拼时单打 a、o、e 也出啊、哦、呃，uia 首选「是啊」；编辑栏点在音节中间时光标落到音节分界，后面的拼音不再变乱码；goushangren 首选「够伤人」；喰能单打，蛇喰梦子成词。
- **笔画**。记住打过的词，笔画多打少打都能出，长按「忘记」能删；导入的词库和「词 笔画编码」格式的笔画词库都能用。
- **候选栏和拼音显示**。自造词的编辑角标缩小、不占宽度，可在设置里关掉；拼音默认仍是浮在键盘上方的气泡，紧贴候选上方的一行小字可选；非中文常用符号补成一类，打符号名出符号。
- **九键**。左栏拼音换了就回到第一个，选完一段后下一段不再停在下面。
- **键盘底部**。三星等三键导航时底部按钮不再被挡；开玻璃时悬浮键盘底部不再多一条亮横条；悬浮键盘拖动更跟手。
- **实体键盘**。组词时 Tab、方向键移到哪个候选，空格就上屏哪个；悬浮候选翻页不再缩窄，第一组宽度不跳。
- **剪贴板**。「全部」里的图片按来源各留最新一张；「完整」图片铺满卡片宽度；干净链接不再丢掉 B 站搜索、收藏夹参数和维基链接结尾的括号。
- **语音**。开车连续语音改叫连续语音，续听前不被打断；屏蔽外放音时应用不理会就改静音。
- **其他**。模型市场读网上模型目录，内置模型出新版不用升级 App；键盘收起后回收内存；横屏手写公式预览不再压住画板；生僻字手写题目不再显示成乱码；三行错位可向左右两边调；iOS 渐变主题不再闪白；符号面板去掉重复格子。

轻量版语音引擎、生僻字和日语手写模板用到时下载；完整版内置离线模型。两者使用相同版本号和安装序号，支持保留数据覆盖安装。
